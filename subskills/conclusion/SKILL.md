# Conclusion

先读 [主 skill](../../SKILL.md)。以实际方法、结果和贡献为输入，结论不是新的研究提案。本段词数建议取 150-200，硬上限为 250 词。

**本章严禁分小节。**

## 段落功能

起草时可按 [模板指南](references/template-guide.md) 使用 LaTeX 结构骨架，并按实际研究内容调整。

先凝练本文处理的问题和方案，再总结证据支持的关键机制价值，最后说明研究意义。可用一个或少量紧凑段落。充分总结文章 problem definition、methodology、results and discussions 三章内容。

### 逻辑结构

文章将研究目标形式化成了一个怎样的问题 -> 对该问题提出了怎样的分析与洞察 -> 基于此，形成了哪些核心创新点，具有怎样的理论创新机制 -> 实验的哪些对比结果彰显了本文方案的哪些优势 -> limitations and future work。

## 写作规则

- 强调完成研究后建立了什么认识，采用确定但与证据相称的肯定表达。
- 回应引言目标与贡献，但严禁逐条复制贡献列表，不再重复介绍完整架构或训练流程。
- 重点解释已经验证的创新价值。
- 使用定性综合判断，严禁复述实验图表数字或引入新的结果、文献论点或证据外主张。
- 着重将各具体机制的作用与实验得到的相应定性结论进行关联，避免空泛描述。
- 本章内，除 limitations and future work 外的部分，严禁使用任何否定语气。
- 使用恰当的连接词，准确描述语句之间的关系。

## 验收与交付

修订时，先写修改详案，用户批准后再落盘。结论的修改详案必须包括整个结论的原文及其翻译、改文及其翻译、修改理由和对应的正文内容六部分。

- 逻辑结构流畅，基本符合本 skill 要求。
- 不存在复述实验图表数字或引入新的结果、文献论点或证据外主张的问题。
- 不存在逐条复制贡献列表或与正文内容重复冗余的问题。
- 不存在空泛描述。
- 除 limitations and future work 外的部分，不存在任何否定语气。
- 句子间衔接恰当，使用能准确描述句子或子句间关系的连接词。
- 篇幅在硬限制以内。
