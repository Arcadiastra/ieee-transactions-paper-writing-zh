# 引用的学术规范核查

## 四个独立结论

核查时分别回答以下问题，不能用一个“已验证”状态合并：

1. 书目结构是否有效：引用 key、必要字段、重复条目和实际引用范围。
2. 出版身份是否一致：题名、作者、版本、出版渠道、年份、卷期页和 DOI。
3. 出版状态是否有变化：更正、撤稿、关注声明及其对本次引用的影响。
4. 文献是否支持当前句子：研究对象、条件、方法和结论是否与正文主张一致。

前三项可部分自动化；第四项必须阅读相关原文。API 命中、论文标题相似、引用次数高或期刊分区高，均不能代替支持关系核查。

## 原文核查流程

- 从具体待引用句出发，标记引用用途：背景、定义、方法来源、基线、数据/工具来源或实质结论。
- 定位原文的页码、小节、公式、图表或实验条件，记录最小必要证据及可访问来源。只看到摘要时，明确证据范围为摘要。
- 对照任务对象、数据来源、假设、比较条件与结论强度；区分原文直接结论、本文推导及一般背景。
- 对支持关系标为“支持”“部分支持”“不支持”或“未核实”。结果不依赖文献名气；没有全文时不凭记忆补出结论。
- 修订提案可以调整引用位置、拆分复合论断或缩小表述范围，仍遵守主 skill 的作者批准流程。不自动换文献、不改变 citation key。
- 出版状态有通知时先读通知：更正不等于全文无效，撤稿引用可能用于研究该事件。将具体影响交作者判断，不能静默删除。

## 审查记录模板

每个重点论断使用以下字段；模板是审查材料，不自动插入论文正文。

| 字段 | 填写内容 |
| --- | --- |
| 正文位置与原句 | 文件/段落及准确原句 |
| Citation key 与版本 | 保留现有 key，注明正式版、预印本或其他版本 |
| 引用作用 | 背景、方法、基线、数据、工具或结论支持 |
| 可核查来源 | 出版方页面、DOI、原文或已授权材料 |
| 证据位置 | 页码、小节、公式或图表 |
| 证据摘要 | 自己概括必要内容，避免复制大段原文 |
| 条件与差异 | 对象、假设、数据与证据强度的对应关系 |
| 出版状态 | 已检索通知、存在通知或尚未核实；附检查日期 |
| 判定 | 支持 / 部分支持 / 不支持 / 未核实 |
| 建议与审批 | 拟修改内容及作者是否批准 |

## 分区与来源

按 citation skill 要求筛选来源时，应记录 JCR 年份及学科类别；多学科分区不可任意选择最有利的一档而不说明。没有权威来源或访问权限时保留“未核实”，不从普通搜索摘要猜分区。文献预算是写作约定，不是引用真实性或相关性的证明。
