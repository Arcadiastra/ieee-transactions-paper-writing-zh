# Results and Discussions

先读 [主 skill](../../SKILL.md)，再对照问题分析、方法机制与真实结果资料。写作任务不自动授权新增实验。本章推荐长度为 2.0-3.0 页，硬上限为 3.5 页。

直接划分为若干子章节。至少包含实验设计、baselines 方法与指标简介、主实验结果三个子章节。根据文章具体实现，可将 baselines 方法与指标简介分开，或在主实验结果后添加其他辅助实验的结果说明。

## 目标与输入

起草时可按 [模板指南](references/template-guide.md) 使用 LaTeX 结构骨架，并按实际研究内容调整。

本章应在已有 contributions 的前提下，基于真实实验设计与结果撰写。

## 逻辑结构

### 实验设计

1. 实验系统简介：必须写明实验采用的相关场景系统及其元数据和数据来源，若为官方 Case，写明其官方代号。此处必须为每个系统都附可视化结构图，若版面超支，可画进同一个图里。
2. 数据生成与处理：简单介绍所使用的仿真或求解工具与相关配置，交代引言中提到的本研究所面向实验场景的具体模拟/配置，以及相关前置假设。若篇幅受限，本章无需明确列出数据，如参数设计、数据集规模等。
3. 实验硬件设备简介，包括 CPU、RAM、GPU（如用到）等的具体型号和数量/大小。最好不要超过 3 行 PDF，但绝对不可不写。

数据总量、全部划分、超参数、调参流程、计算复杂度若非核心贡献或论据，不展开。建议只保留必要的、后文直接引用的、影响比较含义或有关论文贡献与创新性的设置说明。

### baselines 方法与指标简介

baselines 方法采用总-分结构：首先总写一小段提示语，列举所有 baselines 方法，然后分写每种方法的具体设计。分写时，相近的方法可以放在一起说明，其他研究中的方法建议添加相关引用。大部分 baselines，在分写中一句话带过，交代其核心实现特点即可。对于特殊的、与理论创新点直接相关的重要 baseline，可单独成段分析。

若篇幅空间足够，baselines 方法分写建议使用无序列表；若篇幅需要压缩，分写部分可压缩到同一自然段内。

指标简介部分，与问题定义章节和方法论章节照应，使用相关具有普适性的、意义明确的指标，并给出指标定义。若篇幅超支，可省略对常规指标的具体说明。

### 主实验结果

若该组结果较多，可在篇幅允许时采用跨栏大图。根据论文实际贡献情况，如有需要，可分为多个主实验，各自分配一个子章节。

**严禁复述图表中的具体数值、百分比或逐项另算出的数值增益。** 图表承载数据，正文承担对比分析、趋势分析等机制性的定性解释，并扣回 problem definition 与 methodology 中提到的相应 contributions。

按“定性观察 -> 问题分析中的困难 -> 方法章节的具体机制 -> 支持的贡献”组织段落，严禁只用一组 superior、robust、effective 等粗泛程度词代替分析。

按照总-分的观察与行文顺序，先观察分析总体特征与趋势，然后再落到具体的场景对比分析、特定曲线或点分析上来。

注意相关性与因果性的区分。

### 辅助实验结果

参照主实验结果的方式撰写，不要重复相同结论。同样要求支持部分创新点，或从其他侧面支持主实验未完全覆盖的创新点。

## 写作规范

- **严禁写成实验报告：** 无需做到 100% 可复现！只需交代清楚必要的关键设计即可。尽量不在正文列数字，结果用图表展示，正文承担机制性的定性解释。
- **若出现容易被质疑的反例，注意解释方式。严禁使用否定语气加以限制，而是正面分析可能的波动。**
- 通常无需报告多随机种子。鲁棒性不必然需要多随机种子支持。

## 图表选型

| 呈现方式 | 适用目的                                           | 避免                                     |
| -------- | -------------------------------------------------- | ---------------------------------------- |
| 折线图   | 横轴连续或有真实顺序，展示趋势、退化、敏感性或过程 | 将无序的方法类别连线造成连续性暗示       |
| 柱状图   | 离散方法、模块组合、消融或少量场景之间的比较       | 密集分组、过多颜色、难以对应的方法图例   |
| 表格     | 精确值查阅、多指标紧凑比较、协议差异或定性属性     | 与同一结果图重复、把所有实现参数列成大表 |

- 同一数据默认只需采用一种主要展示方式。
- 多面板应共享清晰的比较主题，**相同方法在各图表中的颜色和排序保持一致**；适当区分线型或标记以增强黑白可读性。
- 指标方向、单位、坐标范围和图例清楚。通过适当调整指标选取、坐标尺度与起终点等方法，在保持数据来源真实、同一指标下不同方法采用的坐标范围一致的前提下，突出本研究方法的视觉优势。

## 验收与交付

- 基本按照本 skill 要求的逻辑结构组织。
- 足够简洁直接。
- 图表本身、图表与正文表述不重复，选型恰当。
- 符合写作规范。
- 包含本 skill 要求的必需内容和子章节。
- 篇幅在硬限制以内。
