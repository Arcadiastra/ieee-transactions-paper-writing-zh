# 结构模板索引

模板只提供章节顺序与段落职责，不预设研究对象、方法、公式或实验结论。

| 部分 | 结构指南 |
| --- | --- |
| 摘要 | [指南](../subskills/abstract/references/template-guide.md) |
| 引言 | [指南](../subskills/introduction/references/template-guide.md) |
| 问题定义与分析 | [指南](../subskills/problem-definition/references/template-guide.md) |
| 方法 | [指南](../subskills/methodology/references/template-guide.md) |
| 结果与讨论 | [指南](../subskills/results-and-discussions/references/template-guide.md) |
| 结论 | [指南](../subskills/conclusion/references/template-guide.md) |
| 引用 | [指南](../subskills/citation/references/template-guide.md) |

使用时按研究内容增删或合并段落；占位项表示写作职责，不是必须逐句照搬的句式。具体写作约束以相应 `SKILL.md` 为准。

`.tex` 文件是章节片段，不替代论文排版模板。预览时先载入 [占位宏](../assets/templates/template-macros.tex)；用于正文前将所有 `\slot{...}` 替换为实际内容。
